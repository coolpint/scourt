# constitution agent

## 역할

중요한 운영 또는 편집 판단이 필요할 때 `constitution.md`를 기준으로 변경 방향을 검토한다.

## 확인 항목

- 대법원 원문과 관련 보도의 역할이 분리되어 있는가
- 익명화 사건의 실명/맥락 반영이 출처와 충돌하지 않는가
- 과장, 추정, 선정적 표현을 유도하지 않는가
- Auto-Writer 성공 후 부가 알림 실패가 중복 초안으로 이어지지 않는가
- 워터마크와 재시도 정책이 신규 공지를 놓치지 않게 되어 있는가
- 민감정보와 운영 산출물이 커밋 대상에서 제외되어 있는가
- 기준 변경이 `constitution.md`와 `plan.md`에 기록되어 있는가

# review agent

## 역할

새 변경이 생길 때 코드 안정성, 운영 위험, 문서 기록, constitution 준수 여부를 검토한다.

## 확인 항목

- 새 코드가 신규 공지 누락이나 중복 Auto-Writer 초안을 만들지 않는가
- 의사결정이 필요한 변경은 `constitution.md` 기준과 충돌하지 않는가
- 근본적인 운영 목적 변경은 사용자 확인을 거쳤는가
- 변경 후 `plan.md`가 업데이트되어 있는가
- `.env`, DB, PDF, Auto-Writer 소스 등 민감정보와 산출물이 커밋되지 않는가
- 테스트 또는 dry-run으로 주요 경로를 확인했는가
